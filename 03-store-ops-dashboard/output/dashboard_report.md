# 餐饮门店经营诊断看板

> 基于北京市 4.4 万餐饮商铺真实数据 ｜ 门店健康分层 + 商圈/菜系诊断 + 风险识别

## 一、分层规则

- 高评分：评分 ≥ 4.5；高流量：评论数量 ≥ 中位数 6 条
- A 明星店（高评分 × 高流量）/ B 潜力店（高评分 × 低流量）
- C 口碑风险（低评分 × 高流量）/ C 边缘店（低评分 × 低流量）
- D 评分缺失（无评分门店，多为无评论新店）
