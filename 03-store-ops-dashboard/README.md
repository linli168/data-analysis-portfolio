# 餐饮门店经营诊断看板

> 数据分析实战 ｜ 基于北京市 **44,512 家餐饮商铺真实数据** ｜ 门店分层 + 商圈/菜系诊断 + 风险识别

> 📂 数据分析项目集 · 项目三

## 项目简介

用真实餐饮商铺数据构建"门店经营诊断"看板：对 4.4 万家门店做健康分层，识别口碑风险门店，并从**商圈**和**菜系**两个维度定位经营问题，输出可交互查看的自包含 HTML 看板与风险门店清单。

## 核心发现（基于真实数据）

| 指标 | 数值 |
| --- | --- |
| 门店总数 | 44,512 家 |
| 有效评分率 | 39.2%（60.8% 门店无评分） |
| 平均评分（有评分门店） | 4.53 |
| 人均消费中位数 | 37 元 |
| 风险门店占比（C 类） | 12.8%（5,706 家） |

**门店分层**（评分 ≥ 4.5 且评论量 ≥ 中位数 6 条为高）：

| 分层 | 含义 | 数量 |
| --- | --- | --- |
| A 明星店 | 高评分 × 高流量 | 6,252 |
| B 潜力店 | 高评分 × 低流量 | 5,491 |
| C 口碑风险 | 低评分 × 高流量 | 2,967 |
| C 边缘店 | 低评分 × 低流量 | 2,739 |
| D 评分缺失 | 无评分（多为无评论新店） | 27,063 |

## 分析维度

1. **门店健康分层**：评分 × 评论量四象限（明星/潜力/口碑风险/边缘），无评分门店单独归入 D 类待观察
2. **商圈诊断**：C 类门店占比 Top15（风险聚集地）、评分缺失率 Top15（数据与运营盲区）
3. **菜系画像**：主要菜系的人均消费 × 平均评分 × 门店规模
4. **价格分布**：人均消费分布与 0 值占位比例
5. **风险清单**：C 类门店按"低评分 + 高评论量"排序输出（脱敏，不含店名/地址/电话）
