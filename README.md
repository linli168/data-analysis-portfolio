# 数据分析项目集（Data Analysis Portfolio）

> 数据分析 / 产品运营方向个人作品集 ｜ Python · Pandas · Scikit-learn · 统计推断 · 数据可视化

本仓库汇总个人在数据分析与产品运营方向的项目实践，按「**数据处理 → 实验分析 → 经营看板**」三大能力模块组织，每个项目均为独立文件夹，可单独查看与运行。

## 项目列表

| # | 项目 | 方向 | 数据 | 关键产出 |
| --- | --- | --- | --- | --- |
| 1 | [餐饮大数据预处理与经营分析](01-restaurant-data-processing/) | 数据处理 · 统计分析 | 真实数据（4.4w 门店 / 21w 评论） | 缺失机制判定（MAR）、MICE 多重插补、情感分析、完整报告与图表 |
| 2 | [首页促销卡 A/B 实验](02-ab-test-promo-card/) | 实验设计与统计推断 | 模拟数据 | SRM / A-A 校验、漏斗拆解（CTR×PCVR）、分群决策建议、分析报告 |
| 3 | [餐饮门店经营诊断看板](03-store-ops-dashboard/) | 经营分析 · 可视化 | 真实数据（4.4w 门店） | 门店健康分层、商圈/菜系诊断、脱敏风险清单、自包含 HTML 看板 |

## 能力地图

- **数据处理与清洗**：Pandas、缺失值机制判定（MCAR / MAR / MNAR）、异常值处理、特征工程、MICE 多重插补
- **统计推断与实验**：双比例 z 检验、A/A 校验、SRM 分流检查、漏斗拆解、异质性分群（HTE）、偏相关分析
- **业务分析**：门店分层、商圈/菜系经营诊断、投放效果评估、预算分配逻辑
- **可视化与交付**：Matplotlib、自包含 HTML 看板、Markdown 分析报告

## 使用说明

每个项目文件夹内均包含：

- `README.md` —— 项目背景、方法、结论与运行方式
- 源代码（Python 脚本）
- 输出产物（分析报告、图表、看板）

各项目依赖与运行命令见对应 README。
