# 首页促销卡「低价提醒」A/B 实验分析

> 产品运营数据分析实战 ｜ Python + 双比例 z 检验 + 漏斗拆解 + 分群分析（HTE）

## 项目简介

移动点单 App 计划在首页促销卡片上增加「低价提醒」角标（方案 B），与现状（方案 A）做对照实验，回答两个业务问题：

1. 角标能否让更多用户点击促销卡（**CTR 提升**）？
2. 点击后能否真正带来更多订单（**CVR 提升**）？

项目完整演示了一个规范的 A/B 实验分析流程：**实验设计 → 数据模拟 → 数据质量校验（SRM / A/A）→ 整体显著性检验 → 漏斗拆解 → 分群分析（HTE）→ 业务决策建议**。

## 核心结论（基于本项目模拟数据）

| 指标 | 方案 A | 方案 B | 相对提升 | 显著性 |
| --- | --- | --- | --- | --- |
| 点击率 CTR | ~12% | ~16% | **+30% 左右** | 显著 |
| 点击后转化率 PCVR | ~31% | ~28% | **-10% 左右** | 显著 |
| 整体转化率 CVR | ~3.9% | ~4.4% | **+13% 左右** | 显著 |

**决策建议**：
- 一二线城市：点击与转化同步提升，**建议放量上线**；
- 三四线及以下：点击率提升但点击后转化率明显下降（起送门槛/凑单摩擦），**建议先优化承接体验再验证**；
- 老客对价格更敏感，需关注客单价稀释，建议补充 GMV / 客单价守卫指标。

> 具体数字以实际运行结果为准（数据为带固定随机种子的模拟数据，可完全复现）。

## 方法说明

- **分流**：基于 `user_id` 的稳定 hash 分流（50/50），同一用户始终在同一组，模拟真实实验平台
- **指标**：CTR = 点击/曝光；PCVR = 转化/点击；CVR = 转化/曝光；**CVR = CTR × PCVR**，用于拆解变化来源
- **统计检验**：双比例 z 检验（pooled 标准误），给出 95% 置信区间与 p 值
- **数据质量**：SRM 分流均衡性检验（卡方）+ A/A 检验（对照组内随机拆分，验证随机化与指标口径）
- **分群（HTE）**：城市线级 × 用户类型独立分群，识别差异化放量策略
